Monopoly Deal Card Game

Game Objective

Be the first player to complete 3 full property sets (all cards of a matching color group).

Basic Rules

Turn Structure (30 seconds per turn)

Draw Phase: Draw 2 cards from Draw Pile Play Phase: Play up to 3 cards (Money, Property, or Action cards) Discard Phase: If hand has more than 7 cards, discard down to 7

Card Types

Property Cards: Build color sets to win Money Cards: Pay rent or add to bank (values: 1M, 2M, 3M, 4M, 5M, 10M) Rent Cards: Collect rent from all players for a specific color Action Cards: Special effects like Deal Breaker, Sly Deal, Birthday, Debt Collector, Forced Deal, House, Hotel, Double Rent Just Say No: Negate any action card played against you

Win Condition

Complete 3 full property sets. You win immediately.

Quick Controls

Play a card: Click the card in your hand, then click a valid target End turn: Click the "End Turn" button View card details: Hover your mouse over any card Just Say No: Click the "Reject" button when an action is played against you

Multiplayer

Supports 2 to 5 players Create a private room and share the room code Join an existing room using a room code Real-time gameplay with action history log
